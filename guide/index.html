账号星图 Atlas 安装图解：安卓和 iPhone 都能装

适用于 Android 8.0 及以上、iOS 17 及以上。

因为没上应用商店，确实比点一下“获取”麻烦一点。这篇就一步一步、带图讲清楚。整个 App 免费、没广告，放心装。

先找到你的手机：

  • 安卓：直接下载 APK 安装，三分钟搞定 👉 跳到安卓
  • iPhone：最省事是把网页版添加到主屏幕；想要原生版就得借电脑自签一下 👉 跳到 iPhone

安卓手机

⬇ 下载安卓版 Atlas.apk（3.62 MB）
🔑 蓝奏云密码 0874点下载会自动复制密码，打开后直接粘贴
安卓 8.0 及以上 · 当前版本 v2.3.3 · 下载慢可以走 GitHub Releases 备用链接

第 1 步：下载，点“仍然下载”

点上面的按钮。浏览器会提示“此类文件可能会损害设备”——所有不是从应用商店来的 APK 都会弹这个，点 “仍然下载” 就行。

在微信、QQ 里点链接是下不了的，先点右上角“⋯”，选 “在浏览器打开”。

第 2 步：打开下载好的文件

下载完通知栏会有提示，直接点它。找不到的话，去浏览器的“下载内容”，或者文件管理的 “下载 / Download” 文件夹，点 Atlas.apk。

第 3 步：允许“安装未知应用”

第一次装 APK，系统会拦一下。点弹窗里的 “设置”，把当前这个浏览器（或者文件管理）的 “允许来自此来源的应用” 打开，再按返回。

不同牌子的手机会多一道关：

  • 小米 / HyperOS：会弹“风险提示”或要求联网扫描，勾选“我已知晓风险”，点继续安装。
  • 华为 / 鸿蒙：纯净模式开着会直接拦截。设置里搜 “纯净模式”，先关掉（装完可以再开回去）。
  • OPPO / vivo：可能要你验证账号密码，或者点 “继续安装”、“无视风险安装”。

第 4 步：安装，打开

回到安装界面点 “安装”，几秒就好。装完点“打开”，或者去桌面找 账号星图 的图标。

安装包一直用同一个签名密钥签的。以后出新版本，直接下载新的 APK 覆盖安装就行，不用卸载，数据也都还在。

iPhone

iPhone 有两条路，按自己情况选：

方法一：网页版添加到主屏幕方法二：原生 App（IPA 自签）
要不要电脑不用要（Windows / Mac 都行）
难度⭐⭐⭐⭐
体验全屏、能离线，跟 App 很像原生动画和触感反馈更顺
麻烦的地方没有免费 Apple ID 签名 7 天过期，要重签

不想折腾就选方法一，功能是一样的。

方法一：网页版添加到主屏幕（推荐，不用电脑）

1. 用 Safari 打开 https://huichen.dev/account-atlas/。iOS 26 点右下角的 “⋯”，再点“分享”；旧版本直接点底部的分享按钮（方框加向上箭头）。

2. 往下滑，点“添加到主屏幕”。

3. 点右上角“添加”。 桌面就多了一个账号星图，点开是全屏的，断网也能用。

方法二：安装原生版 IPA（需要电脑）

⬇ 下载 iPhone 原生版 Atlas.ipa（4.07 MB）
🔑 蓝奏云密码 0874点下载会自动复制密码，打开后直接粘贴
需要 iOS 17 及以上 · 未签名，需自签安装 · 备用：GitHub Releases

这个 IPA 是 没签名 的（我没交苹果每年 99 美元的开发者费 😂），所以要用你自己的 Apple ID 签一下再装。建议注册一个小号 Apple ID 专门用来签名。

第 1 步：在电脑上签名并安装

最省心的是 爱思助手（Windows / Mac 都有）。手机用数据线连上电脑，然后：

  • 顶部点 工具箱
  • 点 IPA签名
  • 添加 IPA，选刚下载的 Atlas.ipa
  • 选 “使用 Apple ID 签名”，登录你的 Apple ID
  • 点 开始签名，签好后在“我的设备 → 应用游戏 → 导入安装”里装到手机

不想装爱思的话，也可以用 Sideloadly：把 IPA 拖进去，填 Apple ID，点 Start，一步装完。

第 2 步：信任开发者

装好第一次点开，会提示“不受信任的开发者”。去 设置 → 通用 → VPN与设备管理，点你的 Apple ID 那一项，再点 “信任”。

第 3 步：打开开发者模式

iOS 16 及以上还要多一步：设置 → 隐私与安全性 → 拉到最底 → 开发者模式，打开后按提示重启，解锁后再选一次“打开”。

⚠️ 7 天有效期：免费 Apple ID 签出来的 App 只能用 7 天，过期后点开会闪退，用爱思重新签一遍、覆盖安装就好，数据不会丢。嫌麻烦的话可以用 SideStore，它能在手机上自动续签。

装好之后长这样

左右滑卡片切换账号，点“+”加一个邮箱或手机号，再把它绑过的 App 点一点就记好了。
