用 SideStore 安装 Atlas：自动续签

电脑只用一次，之后在手机上就能安装 IPA、续签 7 天有效期。

用免费 Apple ID 自签的 App 只有 7 天有效期，过期就得连电脑重签一次。SideStore 解决的就是这个问题：电脑只在第一次安装时用一下，之后安装 IPA、续签都在手机上完成。

整体分三步：先在手机上装好 SideStore，再用它装 Atlas.ipa，最后让它帮你续签。

💡 如果你只是想用 Atlas、不在意原生动画，直接用网页版添加到主屏幕更省事，永远不过期。

准备工作

  • 一台 iOS 15 及以上、设置了锁屏密码的 iPhone（Atlas 本身需要 iOS 17 及以上）
  • 一台电脑：Windows 8 以上 / macOS / Linux 都行，只在第一次安装时用
  • 一个 Apple ID，建议注册一个小号专门用来签名
  • 一根数据线，和一个 Wi-Fi（官方要求 Wi-Fi，手机流量不行）
  • 下载好的 Atlas.ipa（蓝奏云网盘 或 GitHub Releases），存到 iPhone 的“文件”App 里

1. 手机上装 LocalDevVPN

SideStore 靠一个“本机 VPN”跟系统通信，它不连外部服务器、不耗电、也不会追踪你。

  1. 在 App Store 搜索安装 LocalDevVPN。
  2. 打开它点 Connect，弹出“添加 VPN 配置”时点 允许 并输入锁屏密码。

以后每次用 SideStore 安装、更新、续签时，LocalDevVPN 都要处于连接状态。

2. 电脑上装 iloader

iloader 是官方推荐的电脑端安装工具，在 iloader.app 下载对应系统的版本：

  • Windows：先装 iTunes（建议用苹果官网版），再装 iloader（推荐 MSI 安装包）。32 位 Windows 和 ARM 版 Windows 10 不支持。
  • Mac：下载 dmg 直接安装。
  • Linux：先装好 usbmuxd，再装 iloader 的 deb / rpm / AppImage。

安装 SideStore

在电脑上

  1. 数据线连接 iPhone 和电脑，手机上弹出“要信任此电脑吗”就点 信任 并输入密码。
  2. 打开 iloader，登录你的 Apple ID（可以不是手机上登录的那个，注意区分大小写）。
  3. 选择你的 iPhone。
  4. 点 Install SideStore (Stable)，等它装完。

在 iPhone 上（iOS 18 及以上）

  1. 打开 设置 → 通用 → VPN与设备管理，在“开发者 App”下点你的 Apple ID，选 信任，再点 允许并重启，输入密码确认。
  2. 去 设置 → 隐私与安全性，拉到最底打开 开发者模式，手机会重启。
  3. 打开 LocalDevVPN，点 Connect。
  4. 打开 SideStore，登录刚才在 iloader 里用的那个 Apple ID。
  5. 进入 My Apps，点 SideStore 右边的 “7 DAYS” 手动刷新一次，完成初始化。弹窗问要不要撤销或新建证书，点 Yes 或 Refresh Now。

成功后 SideStore 会自动退回桌面并弹个通知，几秒后就能再打开了。

iOS 16–17：步骤一样，只是第 1 步点“信任”就行，不用重启。iOS 15 不需要开发者模式。

⚠️ 装好后先刷新 SideStore 自己，再去装别的 App，否则之前装的 App 可能会消失。

用 SideStore 安装 Atlas

  1. 确认 LocalDevVPN 已连接。
  2. 打开 SideStore，进入 My Apps，点左上角的 “+”。
  3. 在“文件”里选择下载好的 Atlas.ipa。
  4. 等它签名、安装完成，桌面就会出现 账号星图。

以后 Atlas 出新版本，同样用“+”选新的 IPA 覆盖安装就行，数据还在。

续签：不再每 7 天找电脑

My Apps 里每个 App 右边都有一个天数，表示还剩几天过期。

  • 手动续签：打开 LocalDevVPN → 打开 SideStore → 点 App 右边的天数，就刷新回 7 天。
  • 自动续签：SideStore 会在后台定期刷新。平时让 LocalDevVPN 保持连接，就基本不用管。

建议养成习惯：每隔几天打开一次 SideStore 看看天数，别等到最后一天。
