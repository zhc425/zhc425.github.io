功能

  • 点选添加内置 100+ 常用网站和 App，多选后指定邮箱或手机号。
  • 隐私模式号码和账号名一键打码，截图分享也安心。
  • 加密同步（可选）本地 AES-GCM 加密后存入你自己的 Gitee 或 GitHub 私密 Gist。
  • 数据在本地没有服务器，不记录密码；支持 JSON 导入导出，离线可用。
