安装 Atlas

安装失败 / 提示“解析包出错”？

多半是没下载完整。删掉重新下载一次，换个浏览器下也行。如果手机上之前装过别人改过签名的版本，先卸载再装。

提示“有风险”“可能是病毒”，能装吗？

能。系统对所有不是应用商店来的 APK 都会这么说。Atlas 只申请了联网（只用于你自己开启的加密同步）和振动两个权限，不读通讯录、不读短信。官方安装包只在 GitHub Releases 和本站发布，别处下载的（尤其是收费的）都不是官方包，不要装。

iPhone 版过了 7 天打不开了？

这是免费 Apple ID 签名的限制，不是 App 坏了。重新签名覆盖安装，数据都在；或者用 SideStore 自动续签。实在嫌烦，就用方法一的网页版，永远不过期。

数据会不会丢？存在哪？

数据只存在你自己的手机里，我没有服务器，也看不到你的数据。覆盖安装、重签都不会丢；但卸载 App 会把数据一起删掉。所以换手机或卸载前，记得在设置里点 “导出备份” 存一份 JSON，到新设备再导入就行。想多设备自动同步，可以开 Gist 加密同步。

完整步骤见 安装指南。

SideStore 自签与续签

能装几个 App？

免费 Apple ID 同时最多 3 个（SideStore 自己算一个），而且一周内最多签 10 个不同的 App。所以装了 SideStore 和 Atlas 后，还能再装 1 个。

SideStore 登录 Apple ID 报错？

最常见是 Anisette 服务器临时挂了。去 SideStore 的设置里，把 “Anisette URL” 换一个官方服务器再试。

账号里多了一台 iMac / MacBook，安全吗？

那是 Anisette 服务器为了辅助登录生成的虚拟设备，不是真的 Mac，不会上传你的隐私数据。

升级 iOS 或还原手机后不能续签了？

配对文件可能失效了，需要按官方的 Pairing File 教程重新生成一次。

之前用爱思 / Sideloadly 装的 Atlas 怎么办？

不用卸载。直接在 SideStore 里用“+”装一遍同样或更新的 IPA，它会接管这个 App，数据保留。

完整步骤见 SideStore 续签教程；更多细节可以看 SideStore 官方中文文档。
